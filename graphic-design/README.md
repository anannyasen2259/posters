# High-level Summary
These posters are created for advertising various Maryville University Data Dialog lecture series.

* https://lnkd.in/p/gibDuSvn: I used the following steps to accomplish the project:
  * Concept: Promoting the event where the guest speakers are invited to present on various topics for the students
  * Asthetic: Based on stakeholders inputs, I used minimalist approach with a combination of muted and bold colors to create the poster
  * Focal Point: Speaker profile
  * Technical Attributes:
    * Vector Scalability: Fully Vectorized poster, allowing for infinite resize without any loss of quality
    * Created shapes using rectangle tool in Adobe Illustrator
    * Used a combination of muted and bold colors
